How to read the data file?
### Miyake revisited: Validating the factor structure of an open-source cognitive control test battery ###

Attached are the raw data for each task and the aggregated data file used for the Confirmatory Factor Analysis of a cognitive control test battery studying inhibition, updating and shifting in young adults.
Below the meaning of the different variables is explained for each csv file. Please contact us if anything is unclear of if you have any questions (eva.vandenbussche@kuleuven.be).

### Antisaccade_RawData ###
Raw data
The .csv file contains 26 columns: 

Column 1 (ParticipantNr): number of the participant (ranging from 1 to 197)
Column 2 (<U+FFFD>): location of the cue on the screen (either left: Cue_L, or right: Cue_R)
Column 3 (target_A): the target (LeftArrow_L = an arrow pointing to the left on the left side of the screen, LeftArrow_R = an arrow pointing to the left on the right side of the screen, RightArrow_L = an arrow pointing to the right on the left side of the screen, RightArrow_R = an arrow pointing to the right on the right side of the screen, UpArrow_L = an arrow pointing up on the left side of the screen, UpArrow_R = an arrow pointing up on the right side of the screen)
Column 4 (mask): location of the mask on the screen (either left: Mask_L, or right: Mask_R)
Column 5 (corrResp): the correct response on the trial (either a left, right, or up arrow key)
Column 6 (@.thisRepN): current number of repetition of the condition list (e.g. 5 = the fifth repetition of the condition list)
Column 7 (@.thisTrialN): current trial number within that repeat
Column 8 (@.thisN): total trials completed so far
Column 9 (@.thisIndex): the index of the current trial in the original conditions list (e.g. 1 = the first trial in the original conditions list)
Column 10 (Procedure): indicates if this is a practice or main trial, all practice trials are already removed from this file
Column 11 (Block): number of block (always 0 here, only 1 block) 
Column 12 (Cue): location of the cue on the screen, identical to column 2
Column 13 (Target): the target, identical to column 3
Column 14 (Resp): participants' response on the trial (either a left, right or up arrow key)
Column 15 (RT): participants' reaction time on the trial, in seconds
Column 16 (ACC): participants' accuracy on the trial (either correct: 1 or incorrect: 0)
Column 17 (ITI): Inter-Trial Interval, time between the cue and the target in seconds, ranging from 1500 to 3500 ms in 250 ms intervals
Column 18 (Time): elapsed time since the start of the task, in seconds 
Column 19 (Run): how many times this task has been started (0 as default = first run, can be adapted when the task needs to be restarted e.g. due to a technical error, without having to overwrite the previous run)
Column 20 (Gender): participants' gender (female, male or other)
Column 21 (Age): participants' age
Column 22 (Handedness): participants' handedness (left, right)
Column 23 (ScreenWidth): screenwidth of the computer on which the task was administerd, in centimeters
Column 24 (ScreenHz): refresh rate of the computer on which the task was administered, in Hertz
Column 25 (RT_1000): participants' reaction time on the trial, in miliseconds. This is the RT (column 15) multiplied by 1000. 
Column 26 (ERR): participants' error rate on the trial (0: correct trial, 1: incorrect trial). This is equal to 1-ACC (column 16).

Column 14 (Time): elapsed time since the start of the task, in seconds 
Column 15 (Run): how many times this task has been started (0 as default = first run, can be adapted when the task needs to be restarted e.g. due to a technical error, without having to overwrite the previous run)
Column 16 (Gender): participants' gender (female, male or other)
Column 17 (Age): participants' age
Column 18 (Handedness): participants' handedness (left, right)
Column 19 (ScreenWidth): screenwidth of the computer on which the task was administerd, in centimeters
Column 20 (ScreenHz): refresh rate of the computer on which the task was administered, in Hertz
Column 21 (RT_1000): participants' reaction time on the trial, in miliseconds. This is the RT (column 13) multiplied by 1000. 
Column 22 (ERR): participants' error rate on the trial (0: correct trial, 1: incorrect trial). This is equal to 1-ACC (column 14).

### LocalGlobal_RawData ###
Raw data
The .csv file contains 26 columns: 

Column 1 (ParticipantNr): number of the participant (ranging from 1 to 197)
Column 2 (<U+FFFD>): the index of the current trial in the original conditions list (e.g. 1 = the first trial in the original conditions list)
Column 3 (image): the name of the image (from the Stimuli folder) that is presented on this trial
Column 4 (img_global): the global feature of the image (circle, triangle, square or cross)
Column 5 (img_local): the local feature of the image (circle, triangle, square or cross)
Column 6 (resp_global): the correct response for the global feature (circle = d, square = f, triangle = j or cross = k)
Column 7 (resp_local): the correct response for the local feature (circle = d, square = f, triangle = j or cross = k)
Column 8 (switch_A): type of trial (1 = switch trial, 0 = no switch trial)
Column 9 (@.thisTrialN): current trial number within that repeat
Column 10 (@.thisN): total trials completed so far
Column 11 (@.thisIndex): the index of the current trial in the original conditions list (e.g. 1 = the first trial in the original conditions list)
Column 12 (Procedure): indicates if this is a practice or main trial, all practice trials are already removed from this file
Column 13 (Block): number of block (2 blocks, 0 = first block, 1 = second block) 
Column 14 (Frame): type of frame (0 = blue and 1 = yellow or 1 = blue and 0 = yellow, depending on randomized frame color mapping in the PsychoPy code)
Column 15 (Switch): type of trial (1 = switch trial, 0 = no switch trial), identical to column 8
Column 16 (Target): path to stimulus image in the Stimuli folder
Column 17 (Resp): participants' response on the trial (d, f, j or k key press)
Column 18 (corResp): the correct response on the trial (d, f, j or k key press)
Column 19 (RT): participants' reaction time on the trial, in seconds
Column 20 (ACC): participants' accuracy on the trial (either correct: 1 or incorrect: 0)
Column 21 (Time): elapsed time since the start of the task, in seconds 
Column 22 (FrameColor): color of the frame around the stimulus that serves as cue for either the global or local task (blue or yellow)
Column 23 (GlobalColor): the frame color that refers to the global task for this participant (blue or yellow)
Column 24 (LocalColor): the frame color that refers to the local task for this participant (blue or yellow)
Column 25 (RT_1000): participants' reaction time on the trial, in miliseconds. This is the RT (column 20) multiplied by 1000. 
Column 26 (ERR): participants' error rate on the trial (0: correct trial, 1: incorrect trial). This is equal to 1-ACC (column 21).


### PlusMinus_RawData ###
Raw data
The .csv file contains 17 columns: 

Column 1 (ParticipantNr): number of the participant (ranging from 1 to 197)
Column 2 (StartTime): elapsed time from the beginning of the task until the start of that block, in seconds
Column 3 (Procedure): indicates if this is a practice or main block, all practice blocks are already removed from this file
Column 4 (Task): the task of the current block (Plus = add 3 to each number, Minus = subtract 3 from each number, Switch = switch between adding and subtracting 3)
Column 5 (number_list): the list of numbers presented in this block
Column 6 (answers): the list of answers given by the participant
Column 7 (answer_times): the list of elapsed time since the beginning of the task for each answer given by the participant, in seconds
Column 8 (accuracy): participants' total accuracy on that block (i.e. the sum of participants' accuracy for each number, either correct: 1 or incorrect: 0, 30 numbers per block so total accuracy ranging from 0 to 30)
Column 9 (EndTime): elapsed time from the beginning of the task until the participant finished that block, in seconds
Column 10 (Run): how many times this task has been started (0 as default = first run, can be adapted when the task needs to be restarted e.g. due to a technical error, without having to overwrite the previous run)
Column 11 (Gender): participants' gender (female, male or other)
Column 12 (Age): participants' age
Column 13 (Handedness): participants' handedness (left, right)
Column 14 (ScreenWidth): screenwidth of the computer on which the task was administerd, in centimeters
Column 15 (ScreenHz): refresh rate of the computer on which the task was administered, in Hertz
Column 16 (Time_CompleteList): participants' time needed to complete that block, in seconds. This is equal to EndTime (Columns 9) - StartTime (Column 2). 
Column 17 (error_rateERR): participants' total error rate on that block, this is equal to 30 (i.e. the total amount of numbers participants had to answer) - accuracy (column 8).


### NumberLetter_RawData ###
Raw data
The .csv file contains 25 columns: 

Column 1 (ParticipantNr): number of the participant (ranging from 1 to 197)
Column 2 (Task): the task that participants need to do on that trial (Num = number classification task: decide if the number is odd or even, LET = letter classification task: decide if the letter is a consonant or vowel)
Column 3 (Procedure): indicates if this is a practice or main trial, all practice trials are already removed from this file
Column 4 (Block): the type of block (NUM = block with only number classification trials, LET = block with only letter classification trials, MIX = block with both number and letter classification tasks)
Column 5 (Switch): indicates if this trial is a switch trial (1, i.e. when participants need to do a different task than on previous trial) or a no switch trial (0)
Column 6 (CorrResp): the correct response on the trial (0 = F key press and 1 = J key press for participants with an even participant number, opposite response mapping in odd participant numbers)
Column 7 (Target): the target stimulus of that trial, i.e. a number-letter pair, e.g. 6 a
Column 8 (BlockOrder): presented order of blocks for that participant (NUM-LET-MIX or LET-NUM-MIX) 
Column 9 (Resp): participants' response on the trial (f or j key press)
Column 10 (corResp): the correct response on the trial (f or j key press)
Column 11 (RT): participants' reaction time on the trial, in seconds
Column 12 (ACC): participants' accuracy on the trial (either correct: 1 or incorrect: 0)
Column 13 (Time): elapsed time since the start of the task, in seconds 
Column 14 (Color): color of the cue that indicates which task needs to be executed (yellow or blue, this variable has not been used in this final dataset) 
Column 15 (Run): how many times this task has been started (0 as default = first run, can be adapted when the task needs to be restarted e.g. due to a technical error, without having to overwrite the previous run)
Column 16 (Gender): participants' gender (female, male or other)
Column 17 (Age): participants' age
Column 18 (Handedness): participants' handedness (left, right)
Column 19 (ScreenWidth): screenwidth of the computer on which the task was administerd, in centimeters
Column 20 (ScreenHz): refresh rate of the computer on which the task was administered, in Hertz
Column 21 (RT_1000): participants' reaction time on the trial, in miliseconds. This is the RT (column 15) multiplied by 1000. 
Column 22 (@.thisTrialN): current trial number within that repeat
Column 23 (@.thisN): total trials completed so far
Column 24 (@.thisIndex): the index of the current trial in the original conditions list (e.g. 1 = the first trial in the original conditions list)
Column 25 (ERR): participants' error rate on the trial (0: correct trial, 1: incorrect trial). This is equal to 1-ACC (column 16).


### KeepTrack_RawData ###
Raw data
The .csv file contains 30 columns: 

Column 1 (ParticipantNr): number of the participant (ranging from 1 to 197)
Column 2 (@.thisRepN): current number of repetition of the condition list (e.g. 0 = the first repetition of the condition list)
Column 3 (@.thisN): total trials completed so far
Column 4 (cor_resp_1): the correct response on the first target category on the trial (e.g. "giraffe" for the target category "animals")
Column 5 (cor_resp_2): the correct response on the second target category on the trial (e.g. "silver" for the target category "metals")
Column 6 (cor_resp_3): the correct response on the third target category on the trial (e.g. "father" for the target category "relatives")
Column 7 (category_1): the first target category on the trial (e.g. relatives)
Column 8 (Resp_1): participants' response on the first target category on the trial
Column 9 (ACC_1): participants' accuracy of the recalled last word of the first target category on the trial (either correct: 1 or incorrect: 0)
Column 10 (category_2): the second target category on the trial (e.g. countries)
Column 11 (Resp_2): participants' response on the second target category on the trial
Column 12 (ACC_2): participants' accuracy of the recalled last word of the second target category on the trial (either correct: 1 or incorrect: 0)
Column 13 (category_3): the third target category on the trial (e.g. animals)
Column 14 (Resp_3): participants' response on the third target category on the trial
Column 15 (ACC_3): participants' accuracy of the recalled last word of the third target category on the trial (either correct: 1 or incorrect: 0)
Column 16 (procedure): indicates if this is a practice, a main trial with four target categories in the trial or a main trial with five target categories in the trial (four target categories: main1, five target categories: main2), all practice trials are already removed from this file. 
Column 17 (Block): number of block (1 block, 1 = first block)
Column 18 (Time):  elapsed time since the start of the task, in seconds 
Column 19 (Age): participants' age
Column 20 (Gender): participants' gender (female, male or other)
Column 21 (Handedness): participants' handedness (left, right)
Column 22 (Run): ow many times this task has been started (0 as default = first run, can be adapted when the task needs to be restarted e.g. due to a technical error, without having to overwrite the previous run)
Column 23 (cor_resp_4): the correct response on the fourth target category on the trial (e.g. "red" for the target category "colors")
Column 24 (category_4): the fourth target category on the trial (e.g. colors)
Column 25 (Resp_4): participants' response on the fourth target category on the trial
Column 26 (ACC_4): participants' accuracy of the recalled last word of the fourth target category on the trial (either correct: 1 or incorrect: 0)
Column 27 (cor_resp_5): the correct response on the fifth target category on the trial, NA: no correct response for trials with only four target categories (e.g. "scarf" for the target category "clothes")
Column 28 (category_5): the fifth target category on the trial (e.g. metals), NA: no target category for trials with only four target categories
Column 29 (Resp_5): participants' response on the fifth target category on the trial, NA: no response for trials with only four target categories
Column 30 (ACC_5): participants' accuracy of the recalled last word of the fourth target category on the trial (correct: 1, incorrect: 0, NA: no answer for trials with only four target categories)


### LetterMemory_RawData ###
Raw data
The .csv file contains 18 columns: 

Column 1 (ParticipantNr): number of the participant (ranging from 1 to 197)
Column 2 (@.thisTrialN): current trial number within that repeat
Column 3 (@.thisN): total trials completed so far
Column 4 (@.thisIndex): the index of the current trial in the original conditions list (e.g. 1 = the first trial in the original conditions list)
Column 5 (Procedure): indicates if this is a practice or main trial, all practice trials are already removed from this file
Column 6 (nLetters): the total amount of letters presented in the stream on that trial (4, 5, 7, 9 or 11 letters)
Column 7 (LetterStream): list of letters presented on that trial
Column 8 (CorResp): the correct response on the trial, i.e. a set containing the four last numbers of the letterstream
Column 9 (Resp): participants' response on the trial, i.e. a set of the four letters they recalled on this trail
Column 10 (ACC): participants' total accuracy on the trial (i.e. the sum of participants' accuracy for each letter, either correct: 1 or incorrect: 0, 4 letters that need to be recalled per trial so total accuracy ranging from 0 to 4)
Column 11 (Time): elapsed time since the start of the task, in seconds 
Column 12 (Run): how many times this task has been started (0 as default = first run, can be adapted when the task needs to be restarted e.g. due to a technical error, without having to overwrite the previous run)
Column 13 (Gender): participants' gender (female, male or other)
Column 14 (Age): participants' age
Column 15 (Handedness): participants' handedness (left, right)
Column 16 (ScreenWidth): screenwidth of the computer on which the task was administerd, in centimeters
Column 17 (ScreenHz): refresh rate of the computer on which the task was administered, in Hertz
Column 18 (ERR): participants' total error rate on the trial, this is equal to 4 (i.e. the total amount of letters participants had to recall) - accuracy (column 11).

### DemeyerDePue_DataAggr.csv ###
Aggregated data
The .csv file contains 261 columns:

Column 1 (ParticipantNr): number of the participant (ranging from 1 to 284)
Column 2 (Antisac_Mean_RT): participants' mean reaction time on the Antisaccade task, in milliseconds.
Column 3 (Antisac_Median_RT): participants' median reaction time on the Antisaccade task, in milliseconds.
Column 4 (Antisac_SD_RT): participans' standard deviation of the reaction time on the Antisaccade task, in milliseconds.
Column 5 (Antisac_Mean_ACC): participants' mean accuracy on the Antisaccade task (ranging from 0 to 1)
Column 6 (Antisac_Median_ACC): participants' median accuracy on the Antisaccade task (either 0 or 1)
Column 7 (Antisac_SD_ACC): participants' standard deviation of the accuracy on the Antisaccade task (ranging from 0 to 1)
Column 8 (Antisac_Mean_ERR): participants' mean error rate on the Antisaccade task (ranging from 0 to 1). This is equal to 1-Antisac_Mean_ACC (column 5).
Column 9 (Antisac_Median_ERR): participants' median error rate on the Antisaccade task (either 0 or 1). This is equal to 1-Antisac_Median_ACC (column 6).
Column 10 (Antisac_SD_ERR): participants' standard deviation of the error rate on the Antisaccade task (ranging from 0 to 1)
Column 11 (GlobLoc_Mean_RT_No_Switch): participants' mean reaction time on no switch trials in the Local-Global task, in milliseconds.
Column 12 (GlobLoc_Mean_RT_Switch): participants' mean reaction time on switch trials in the Local-Global task, in milliseconds.
Column 13 (GlobLoc_Median_RT_No_Switch): participants' median reaction time on no switch trials in the Local-Global task, in milliseconds.
Column 14 (GlobLoc_Median_RT_Switch): participants' median reaction time on switch trials in the Local-Global task, in milliseconds.
Column 15 (GlobLoc_SD_RT_No_Switch): participants' standard deviation of the reaction time on no switch trials in the Local-Global task, in milliseconds.
Column 16 (GlobLoc_SD_RT_Switch): participants' standard deviation of the reaction time on switch trials in the Local-Global task, in milliseconds.
Column 17 (GlobLoc_Mean_RT_Switch_Cost): participants' mean reaction time switch cost in the Local-Global task, in milliseconds. This is equal to GlobLoc_Mean_RT_Switch (column 12) - GlobLoc_Mean_RT_No_Switch (column 11).
Column 18 (GlobLoc_Median_RT_Switch_Cost): participants' median reaction time switch cost in the Local-Global task, in milliseconds. This is equal to GlobLoc_Median_RT_Switch (column 14) - GlobLoc_Median_RT_No_Switch (column 13).
Column 19 (GlobLoc_SD_RT_Switch_Cost): participants' standard deviation on the reaction time switch cost in the Local-Global task, in milliseconds. This is equal to GlobLoc_SD_RT_Switch (column 16) - GlobLoc_SD_RT_No_Switch (column 15).
Column 20 (GlobLoc_Mean_ACC_No_Switch): participants' mean accuracy on no switch trials in the Local-Global task (ranging from 0 to 1)
Column 21 (GlobLoc_Mean_ACC_Switch): participants' mean accuracy on switch trials in the Local-Global task (ranging from 0 to 1)
Column 22 (GlobLoc_Median_ACC_No_Switch): participants' median accuracy on no switch trials in the Local-Global task (either 0 or 1)
Column 23 (GlobLoc_Median_ACC_Switch): participants' median accuracy on switch trials in the Local-Global task (either 0 or 1)
Column 24 (GlobLoc_SD_ACC_No_Switch): participants' standard deviation of the accuracy on no switch trials in the Local-Global task (ranging from 0 to 1)
Column 25 (GlobLoc_SD_ACC_Switch): participants' standard deviation of the accuracy on switch trials in the Local-Global task (ranging from 0 to 1)
Column 26 (GlobLoc_Mean_ERR_No_Switch): participants' mean error rate on no switch trials in the Local-Global task (ranging from 0 to 1). This is equal to 1-GlobLoc_Mean_ACC_No_Switch (column 20).
Column 27 (GlobLoc_Mean_ERR_Switch): participants' mean error rate on switch trials in the Local-Global task (ranging from 0 to 1). This is equal to 1-GlobLoc_Mean_ACC_Switch (column 21).
Column 28 (GlobLoc_Median_ERR_No_Switch): participants' median error rate on no switch trials in the Local-Global task (either 0 or 1). This is equal to 1-GlobLoc_Median_ACC_No_Switch (column 22).
Column 29 (GlobLoc_Median_ERR_Switch): participants' median error rate on switch trials in the Local-Global task (either 0 or 1). This is equal to 1-GlobLoc_Median_ACC_Switch (column 23).
Column 30 (GlobLoc_SD_ERR_No_Switch): participants' standard deviation of the error rate on no switch trials in the Local-Global task (ranging from 0 to 1). This is equal to GlobLoc_SD_ACC_No_Switch (column 24).
Column 31 (GlobLoc_SD_ERR_Switch): participants' standard deviation of the error rate on switch trials in the Local-Global task (ranging from 0 to 1). This is equal to GlobLoc_SD_ACC_Switch (column 25).
Column 32 (GlobLoc_Mean_ACC_Switch_Cost): participants' mean accuracy switch cost in the Local-Global task (ranging from 0 to 1). This is equal to GlobLoc_Mean_ACC_Switch (column 21) - GlobLoc_Mean_ACC_No_Switch (column 20).
Column 33 (GlobLoc_Median_ACC_Switch_Cost): participants' median accuracy switch cost in the Local-Global task (either 0 or 1). This is equal to GlobLoc_Median_ACC_Switch (column 23) - GlobLoc_Median_ACC_No_Switch (column 22).
Column 34 (GlobLoc_SD_ACC_Switch_Cost): participants' standard deviation on the accuracy switch cost in the Local-Global task (ranging from 0 to 1). This is equal to GlobLoc_SD_ACC_Switch (column 25) - GlobLoc_SD_ACC_No_Switch (column 24).
Column 35 (GlobLoc_Mean_ERR_Switch_Cost): participants' mean error rate switch cost in the Local-Global task (ranging from 0 to 1). This is equal to GlobLoc_Mean_ERR_Switch (column 27) - GlobLoc_Mean_ERR_No_Switch (column 26).
Column 36 (GlobLoc_Median_ERR_Switch_Cost): participants' median error rate switch cost in the Local-Global task (either 0 or 1). This is equal to GlobLoc_Median_ERR_Switch (column 29) - GlobLoc_Median_ERR_No_Switch (column 28).
Column 37 (GlobLoc_SD_ERR_Switch_Cost): participants' standard deviation on the error rate switch cost in the Local-Global task (ranging from 0 to 1). This is equal to GlobLoc_SD_ERR_Switch (column 31) - GlobLoc_SD_ERR_No_Switch (column 30).
Column 38 (KeepTrack_ACC_27): participants' total number of correctly recalled last words in the Keep Track task (ranging from 0 to 27).
Column 39 (KeepTrack_ERR_27): participants' total number of incorrectly recalled last words in the Keep Track task (ranging from 0 to 27). This is equal to 27-KeepTrack_ACC_27 (column 38).
Column 40 (KeepTrack_ACC): participants' percentage of correctly recalled last words in the Keep Track task (ranging from 0 to 1). This is equal to KeepTrack_ACC_27 (column 38)/27.
Column 41 (KeepTrack_ERR): participants' percentage of incorrectly recalled last words in each target category and trial in the Keep Track task (ranging from 0 to 1). This is equal to KeepTrack_ERR_27/27 (column 39).
Column 42 (PlusMinus_Time_Subtr): participants' time to complete the subtraction block in the Plus-Minus task, in seconds.
Column 43 (PlusMinus_Time_Add): participants' time to complete the addition block in the Plus-Minus task, in seconds.
Column 44 (PlusMinus_Time_Switch): participants' time to complete the alternating block in the Plus-Minus task, in seconds.
Column 45 (PlusMinus_Mean_Time): participants' mean time on the subtraction, addition and alternating blocks in the Plus-Minus task, in seconds.
